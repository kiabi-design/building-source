# Building source RU

Русифицированная версия Android-приложения Building source на основе предоставленного исходного проекта.

## Что изменено

- Добавлен выбор языка `Русский` рядом с English и العربية.
- Добавлен русский перевод основных экранов Build, Libraries, Settings и About, диалогов и системных сообщений интерфейса.
- Переведены названия и описания основных компонентов в каталоге библиотек.
- Переведены уведомления о ходе и завершении сборки.
- Исходные скрипты сборки и механизм загрузки библиотек не менялись.

## Сборка APK

Требуется JDK 17 и Android SDK с платформой API 36.

```bash
./gradlew --no-daemon assembleDebug
```

Готовый APK:

`app/build/outputs/apk/debug/app-debug.apk`

Также добавлен GitHub Actions workflow: **Actions → Build Building Source RU APK → Run workflow**. После успешного выполнения APK можно забрать из Artifacts.

Примечание: в текущей среде сборку APK выполнить не удалось, потому что Gradle Wrapper не смог скачать Gradle с `services.gradle.org` из-за отсутствия сетевого доступа. Поэтому этот архив содержит изменённые исходники, а не готовый APK.
